# 角色总表与双定级草案 v0.1

> 状态：DRAFT / 待人工复核，不封版。
>
> 本表用于决定“哪些人物做正式人物卡、谁先做、武道默认定到哪里”。人物姓名全部保留原名。

## 一、双定级体系

### 1. 剧情级别

- **S｜时代轴心**：决定大势、跨多个篇章反复登场，必须优先制作完整人物卡与能力绿灯。
- **A｜主力人物**：主要战役、阵营或人物关系中的重要支柱，制作完整人物卡；有明确能力体系者同步制作能力绿灯。
- **B｜重要配角**：具有稳定辨识度和明确剧情职责，制作正式人物卡，但优先级低于 S/A。
- **C｜时间线 NPC**：必须出现在时间线或关键事件中，但暂不制作重型人物卡；后续若戏份增长可晋级 B。

### 2. 武道等级

统一使用：`未入武境 / 武卒 / 武人 / 骁将 / 名将 / 无双`。

注意：
- 剧情级别与武道等级完全独立；
- 顶尖军师可以是 S 级但只有武人；
- B 级配角也可能是名将；
- 武道等级是默认制卡锚点，不代表绝对胜负。

## 九、当前不纳入第一轮重型人物卡的类型

- 只因为游戏可玩而存在、但《三国演义》主线职责很弱的人物；
- 高度重复的宗室二代、配偶或陪衬人物；
- 神仙、仙术型角色（例如会直接破坏当前“高武但非修仙”底盘者）；
- 只有单一战役功能、且用 C 级 NPC 足以承载的人物。

因此第一轮不追求复刻《真·三国无双》全部可玩 roster。
