# 名姬女杰扩展与角色池修订 v0.2

> 状态：DRAFT / 待人工复核。
>
> 本修订用于纠正 v0.1 角色池对三国高辨识度女性人物收录不足、剧情权重偏低的问题。她们不是“美女附属角色”，而是《三国无双姬》正式的武姬、谋士、政治人物、外交人物、宗族核心与关系轴角色。

## 一、修订原则

1. 历史、演义、无双体系中具有稳定知名度与视觉辨识度的女性人物，应优先进入正式人物卡池。
2. 不因为某人传统叙事中以“妻子、女儿、皇后、名姬”身份闻名，就自动把她降格成关系附件。
3. 每人至少分配一种独立功能：武姬、谋士、政治家、外交者、宗族核心、近卫、工学家、情报人物、宫廷权力人物等。
4. “美貌”可以是角色魅力与外貌记忆点，但不能是唯一角色定位。
5. 官方《真·三国无双》系高辨识度女性武将原则上至少进入 A/B 正式人物卡池。
6. 人物姓名仍按项目正式原名规则处理。黄月英采用完整常用名“黄月英”；吕玲绮采用官方常用名“吕玲绮”。

## 五、后续审美原则

名姬 / 女杰群体尤其禁止做成“同一种纤细长发美女”。

应主动拉开：
- 高矮；
- 年龄感；
- 肌肉与体脂；
- 发型轮廓；
- 妆容；
- 武器体量；
- 政治型、武斗型、谋略型、艺术型气质。

例如：
- 黄月英应有工学家、机关师的理性和机械感，而不只是“诸葛亮的漂亮妻子”；
- 王异应有冷峻、危险、复仇者气质；
- 大乔、小乔必须姐妹可辨，但不能做成换发色复制体；
- 祝融应保留南中野性与强悍体魄；
- 蔡文姬应把乐律、才学与忧郁气质结合，而不是单纯柔弱文姬；
- 吕玲绮应继承吕布系的压迫感与年轻锐气，但不能成为缩小版吕布。

完整 roster 以 `manifest/character-roster.v0.2.json` 为当前机器草案。
