# 人物条目格式与原名保留规范 v1.0

## 一、适用范围

本规范适用于 `worldbook/characters/main/` 与 `worldbook/characters/other/` 下的全部正式人物条目。

人物正文以咩咩制卡·全栈 v1.0.0 的 `chara-v1` 为唯一母版，在不改变其基本结构的前提下，固定增加四个项目字段：

- 阵营
- 角色定位
- 标志性武器
- 武道等级

这些字段属于《三国无双姬》项目的人物身份摘要，不替代人物能力绿灯。

## 二、人物姓名规则

人物姓名一律保留原版正式姓名，不因本世界全员女性而改名。

例如：
- 曹操仍写作“曹操”；
- 刘备仍写作“刘备”；
- 孙权仍写作“孙权”；
- 吕布仍写作“吕布”；
- 诸葛亮仍写作“诸葛亮”。

禁止使用“曹姬”“刘备娘”“女吕布”等人为性转名作为正式姓名。

本世界的人类自出生起皆为女性，人物性别由世界底层规则决定，不需要通过改名证明女性身份。

## 四、四个新增字段的填写规则

### 1. 阵营

填写人物在当前制卡锚点下的正式政治或军事归属，例如：

- 曹魏
- 蜀汉
- 孙吴
- 晋
- 群雄·董卓军
- 群雄·袁绍军
- 群雄·吕布军
- 汉室 / 朝廷
- 在野

人物若历史上多次转换阵营，人物正文只写当前制卡锚点的所属；完整转阵营过程由时间线和相关绿灯处理，不在静态人物卡中堆叠一生履历。

### 2. 角色定位

用高密度短语概括人物的主要功能与英雄气质，例如：

- 枭雄型君主 / 统帅
- 仁义型君主
- 成长型君主
- 天下第一猛将
- 军师 / 战略家
- 前线统帅 / 名将
- 亲卫型猛将
- 文臣 / 内政官

允许使用 1～2 个互补定位，但禁止写成大段人物简介。

### 3. 标志性武器

只填写最具辨识度的主武器、奇门兵器或代表性兵装名称。

该字段负责“人物识别”，不负责解释招式、武器机制和战斗能力。具体能力、兵器特性与无双招式继续拆入 `<核心设定:角色名·能力>` 绿灯条目。

### 4. 武道等级

统一服从核心设定中的武境体系：

- 未入武境：不以稳定武道修炼见长，或尚未形成正式战斗能力；
- 武卒；
- 武人；
- 骁将；
- 名将；
- 无双。

武道等级只表示当前综合武道层级，不代表绝对胜负，不覆盖军师能力、统率、政治、谋略、伤势、地形与克制关系。

人物可随剧情成长、衰退或受伤而发生武境变化；静态人物正文记录当前制卡锚点的默认等级，剧情变化由时间线与运行时事实覆盖。

## 五、人物能力仍然独立拆分

有明确战斗、谋略、机关、特殊武器或个人能力体系的人物，应另建同名能力绿灯：

```text
<核心设定:角色名·能力>
能力定位:...
核心能力:
- ...
法宝与武器:
- ...
战斗特点:...
限制与代价:
- ...
</核心设定:角色名·能力>
```

人物正文不塞技能树，不写长篇战斗履历，不把角色卡重新做成百科。

## 六、封版原则

- 姓名保留原版；
- 性别固定为女；
- 阵营、角色定位、标志性武器、武道等级为本项目固定新增字段；
- 外貌、性格和战斗表现服从《三国无双姬》已封版核心设定；
- 具体能力继续使用绿灯条目；
- 后续批量人物生产统一以本规范为准。
