# 人物外貌生成与记忆点规范 v1.0

> 本规范用于《三国无双姬》正式人物卡的外貌设计。目标不是把所有角色统一美型，而是让每个人在缩略图、短描写和战场剪影中都能被迅速辨认。
>
> 当前适配人物池：`manifest/character-roster.v0.2.json`，正式人物卡候选 89 人。

## 一、核心原则

### 1. 身高必须有高有矮

禁止把主要人物批量集中在 165～175cm。

89 名正式人物卡的整体身高建议按以下区间控制：

| 身高带 | 范围 | 目标人数 |
|---|---:|---:|
| 极矮 | 148～154cm | 7 |
| 娇小 | 155～160cm | 13 |
| 偏矮 | 161～166cm | 17 |
| 中等 | 167～172cm | 21 |
| 高挑 | 173～179cm | 20 |
| 极高 | 180～186cm | 11 |

合计：89 人。

这些是分布目标，不是机械配额。身高必须服务人物气质和战斗方式：
- 仁义、亲和、灵巧型人物可以很矮；
- 重兵器、骑将、压迫型人物可以更高；
- 君主绝不默认高个；
- 军师绝不默认纤弱矮小；
- 同一阵营也要故意制造高低差。

### 2. 每人必须有 1～2 个鲜明记忆点

每名正式角色至少拥有：

- **一个轮廓级记忆点**：在黑色剪影里仍能辨认，例如极矮身高、极高身高、双马尾、超长高马尾、双丸子、巨大披风、宽肩重甲、夸张袖摆；
- **一个细节级记忆点**：近看才能确认，例如特殊发色、眼罩、发冠、虎牙、泪痣、异色瞳、纹样、伤疤、耳坠、头巾、颈饰。

允许只使用一个记忆点，但该记忆点必须足够强。

禁止：
- 只有“漂亮”“长发”“御姐”这种无法区分人物的描述；
- 同阵营连续出现三名以上同发色 + 同发型；
- 把武器名称当成唯一外貌记忆点；
- 所有人都用长直发、细腰、长腿模板。

### 3. 名姬 / 女杰不能共用“美女模板”

历史、演义与无双体系中以美貌、才名、婚姻或家世闻名的女性人物，也必须首先是独立角色。

设计这批角色时：
- 美貌可以是魅力，但不能替代角色职业与性格；
- 不默认全部娇小、纤细、柔弱、长发；
- 可以有高挑健美、丰满强健、冷峻锐利、野性、学者感、政治家感、近卫感；
- 传统“妻子 / 女儿 / 皇后 / 名姬”身份不得成为唯一外貌来源；
- 姐妹、母女、宗族人物可以共享少量家族特征，但必须保留强烈个人差异。

示例方向：
- 黄月英：机关师 / 工学谋士感，服饰与配件可见机械、量尺、工具、结构件语言；
- 王异：冷峻、危险、复仇者气质，避免柔弱贵妇模板；
- 大乔与小乔：允许共享家族色彩或眼型，但身高、发型轮廓、气质与动作节奏必须明显不同；
- 祝融：南中野性、强悍体魄、投射武姬感；
- 蔡文姬：乐律、才学、忧郁与坚韧并存，不做纯病弱文姬；
- 吕玲绮：继承吕布系锐气与压迫感，但体型、发型、兵器节奏必须与吕布区分；
- 练师：近卫型武姬，应有可靠、沉稳、保护者轮廓；
- 辛宪英：识人谋士，应有清醒、克制、观察者气质。

## 二、体型与身材规范

体型至少在以下方向中分散：

- 娇小纤细
- 娇小结实
- 修长纤细
- 修长运动型
- 标准匀称
- 丰满柔和
- 丰满强健
- 高挑精悍
- 高挑健美
- 宽肩重装型

高武强者不等于男性化体型，也不等于必须巨乳或肌肉夸张。

胸部大小、腰臀比例、肩宽与肌肉量必须独立设计，不能绑定：
- 武道等级；
- 阵营；
- 善恶；
- 智力；
- 年龄。

## 三、年龄表现

人物实际年龄必须保留。

- 青年：皮肤、姿态、动作节奏可轻快；
- 中年：允许更沉稳、成熟、威严，出现轻微眼纹与旧伤；
- 高龄：允许白发、细纹、体力恢复下降与伤病痕迹，但不自动写成佝偻衰弱老妪。

“老年御姐化”只改变审美表达，不重置年龄。

## 四、发型差异化

主要人物之间优先轮换：

- 双马尾
- 高马尾
- 低马尾
- 侧马尾
- 狼尾
- 短发
- 齐肩发
- 长直发
- 长卷发
- 双丸子
- 编发
- 不对称发型
- 半扎发
- 超长垂发

同一人物的发型要与身份、动作方式和武器兼容。

长柄武器、骑战角色要避免大面积散发持续遮挡后背；奇门兵器和灵巧角色可以使用更跳脱的发尾与绑带形成动态轮廓。

## 五、发色与阵营色

阵营色只作为辅助，不是染发制服：

- 曹魏可偏黑、蓝、紫、冷红，但不能全员蓝黑；
- 蜀汉可偏暖色、白、粉、绿、褐，但不能全员绿；
- 孙吴可偏红、橙、金、棕，但不能全员红发；
- 晋可偏紫、黑、银、灰，但不能全员紫发；
- 群雄不设统一颜色。

发色首先服务个人记忆点，其次才考虑阵营协调。

## 六、脸部与细节记忆点

可以使用：

- 粗眉 / 细长眉 / 下垂眉
- 泪痣 / 眼下痣 / 唇边痣
- 单眼伤疤 / 眉间伤疤 / 颈部旧伤
- 虎牙
- 异色瞳
- 特殊瞳色
- 眼罩
- 额饰 / 发冠 / 簪 / 羽饰
- 颈圈 / 玉佩 / 虎符 / 家纹饰品

同一种强记忆点不要滥用。例如眼罩优先留给真正适合的人物，不能十个人都戴。

## 七、甲胄与服饰

全女性社会的衣甲从一开始就按女性身体设计，不使用“男甲改女版”逻辑。

人物服装必须同时表现：
1. 身份；
2. 阵营气质；
3. 武器与动作需求；
4. 个人记忆点。

甲胄允许华丽，但胸甲应以整体曲面、内衬与束带承力，不默认夸张独立胸杯。

军师、君主、文官也可以穿便于行动的礼装、轻甲或战袍，不把“文职”固定成无法行动的长裙。

## 八、武器与剪影

标志性武器必须参与人物整体轮廓设计，但不能取代人物本身的识别度。

优先考虑：
- 武器长度与人物身高的反差；
- 武器重量与身体发力方式；
- 武器收纳位置；
- 骑战时是否妨碍动作；
- 发型与披风是否会和武器发生视觉冲突。

允许故意制造反差，例如：
- 娇小角色使用大尺寸兵器；
- 高挑角色使用精巧短兵；
但必须能从武道与气的设定中解释。

## 十、生成时的硬性检查

每完成一名人物，必须回答：

1. 她站在另外十名角色旁边，能否只看轮廓认出来？
2. 身高是否和人物性格、身份、武器形成了有意义的关系？
3. 记忆点是否重复了同阵营已有角色？
4. 去掉发色之后，是否还剩至少一个可识别特征？
5. 去掉武器之后，是否仍然像这个人物？
6. 是否保留实际年龄感？
7. 是否避免“全员长腿御姐”模板化？
8. 若属于名姬 / 女杰群体，是否拥有独立于婚姻与美貌的职业、战斗、政治或谋略识别点？

有任意两项回答“否”，人物外貌不得进入正式卡。

## 十一、批量生产顺序

角色外貌不要 89 人一次性自动随机生成。

建议：
1. 先确认 S 级 15 人；
2. 再优先确认名姬 / 女杰扩展组，避免她们后补时被迫复用已有造型；
3. 再按阵营制作其余 A 级；
4. 每完成一个阵营，做一次身高 / 发型 / 发色 / 记忆点重复度 QA；
5. 最后补 B 级人物，专门填补当前外貌分布中的空缺区间。

这样可以主动维持角色群像的视觉差异，而不是生成到最后才发现四十个人长得像姐妹。
