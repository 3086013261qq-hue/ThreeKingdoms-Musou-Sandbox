# 人物外貌生成与记忆点规范 v1.0

> 本规范用于《三国无双姬》正式人物卡的外貌设计。目标不是统一美型，而是让每个人在缩略图、短描写和战场剪影中都能迅速辨认。
>
> 当前人物池：`manifest/character-roster.v0.3.json`（89人）。
> 当前逐人外貌锚点：`manifest/character-appearance-anchors.v0.1.json`。

## 一、身高必须真正拉开

89人的身高分布已经实际落位：

| 身高带 | 范围 | 人数 |
|---|---:|---:|
| 极矮 | 148～154cm | 7 |
| 娇小 | 155～160cm | 13 |
| 偏矮 | 161～166cm | 17 |
| 中等 | 167～172cm | 21 |
| 高挑 | 173～179cm | 20 |
| 极高 | 180～186cm | 11 |

合计89人。正式人物生产不得重新随机身高。

身高必须服务人物气质和战斗方式，但允许强烈反差：君主不默认高个，猛将不默认巨人，军师不默认矮弱。袁绍154cm、黄盖154cm、凌统153cm均为有意设计，不是录入错误。

## 二、每人必须有两级记忆点

每名正式角色至少拥有：

- **轮廓级记忆点**：黑色剪影仍能辨认，例如极端身高、双马尾、双丸子、超长高马尾、巨量卷发、巨大披风、宽肩重甲、夸张袖摆；
- **细节级记忆点**：近看确认身份，例如眼罩、发冠、虎牙、泪痣、疤痕、异色瞳、纹样、耳饰、颈饰、家纹饰品。

禁止只写“漂亮、长发、御姐”；禁止把武器当成唯一记忆点；去掉武器后仍必须像这个人物。

## 三、名姬 / 女杰不能共用美女模板

美貌可以是魅力，但不能替代职业与性格。传统妻子、女儿、皇后、名姬身份不得成为唯一外貌来源。

- 黄月英：机关师 / 工学谋士感，工具、量尺、护目镜与结构件语言；
- 王异：冷峻、危险、复仇者感；
- 大乔 / 小乔：允许少量家族相似，但身高、发型轮廓、动作节奏必须明显不同；
- 祝融：高挑健美、南中野性、投射武姬感；
- 蔡文姬：乐律、才学、忧郁与坚韧并存；
- 吕玲绮：继承吕布系锐气，但绝不做缩小版吕布；
- 练师：可靠沉稳的近卫轮廓；
- 辛宪英：清醒克制的观察者气质。

## 四、体型与身材

体型必须分散在娇小纤细、娇小结实、修长纤细、修长运动型、标准匀称、丰满柔和、丰满强健、高挑精悍、高挑健美、宽肩重装等不同方向。

高武强者不等于男性化体型，也不等于必须巨乳或夸张肌肉。胸部、腰臀、肩宽、肌肉量不得绑定武道等级、阵营、善恶或智力。

本阶段先固定整体体型。胸部、腰臀等更细字段在正式人物卡阶段结合**成年制卡锚点**和人物特点补齐；未确认成年锚点前不机械分配。

## 五、年龄表现

实际年龄必须保留。青年可以轻快，中年可以成熟威严，高龄可以白发、细纹、旧伤与恢复下降，但不自动写成佝偻衰弱老妪。“老年御姐化”只改变审美表达，不重置年龄。

## 六、发型与发色

发型优先轮换：双马尾、高马尾、低马尾、侧马尾、狼尾、短发、齐肩发、长直发、长卷发、双丸子、编发、不对称发型、半扎发、超长垂发等。

阵营色只作为辅助：魏可偏黑蓝紫冷红，蜀可偏暖色白粉绿褐，吴可偏红橙金棕，晋可偏紫黑银灰，群雄不设统一色。禁止阵营染发制服。

当前89人分表中，同阵营不存在完全重复的“发色 + 发型”组合。

## 七、甲胄与服饰

全女性社会的衣甲从一开始就按女性身体设计，不使用“男甲改女版”逻辑。服装必须同时表达身份、阵营、武器动作需求与个人记忆点。

甲胄允许华丽，但胸甲以整体曲面、内衬与束带承力，不默认夸张独立胸杯。军师、君主、文官也可穿便于行动的礼装、轻甲或战袍。

## 八、武器与剪影

标志性武器参与整体轮廓设计，但不能取代人物识别度。需要考虑武器长度与身高反差、重量与发力方式、收纳位置、骑战动作、发型与披风冲突。

允许娇小人物拿大兵器，也允许高挑人物用精巧短兵，但必须能由武道与气解释。

## 九、硬锚点示例

- 刘备：151cm，娇小结实，**粉红色双马尾**，翠瞳，白粉短披风。此项视为已确认硬锚点。
- 吕布：186cm，极高健美，超长黑发 + 巨大披风，赤色角状发饰。
- 关羽：183cm，深青超长高马尾，两束极长鬓发，青玉发冠。
- 赵云：180cm，银白高马尾，蓝色长围巾。
- 曹操：173cm，蓝黑高马尾，黑金发冠，暗红眼妆线。
- 袁绍：154cm，娇小优雅，浅金长卷双侧束发，白金冠饰与孔雀羽纹。
- 黄盖：154cm，矮壮强健，霜灰短刺发，晒斑与宽笑纹。
- 凌统：153cm，娇小结实，黑红短狼尾，高速近战轮廓。

## 十、生成时硬性检查

每完成一名人物必须检查：

1. 只看轮廓能否认出？
2. 身高与性格、身份、武器是否形成有意义关系？
3. 记忆点是否撞同阵营已有角色？
4. 去掉发色后是否仍有至少一个识别点？
5. 去掉武器后是否仍像这个人物？
6. 是否保留实际年龄感？
7. 是否避免全员长腿御姐模板？
8. 名姬 / 女杰是否拥有独立于婚姻与美貌的职业、战斗、政治或谋略识别点？

有任意两项回答“否”，不得进入正式人物卡。

## 十一、后续批量生产流程

后续不再边写边随机外貌：

1. 读取 `manifest/character-roster.v0.3.json` 获取阵营、剧情级别、角色定位、标志性武器、武道等级；
2. 读取 `manifest/character-appearance-anchors.v0.1.json` 并按阵营加载对应分表，获取身高、体型、发色、发型、瞳色、轮廓记忆点、细节记忆点、服装方向；
3. 根据人物成年制卡锚点补足年龄表现、胸部、上下装、配饰、鞋子等 `chara-v1` 字段；
4. 有明确战斗 / 谋略 / 机关 / 特殊兵器体系者同步生成 `<核心设定:角色名·能力>` 绿灯；
5. 每批只做一致性QA，不重新随机基础造型。

这样角色正文与能力条目都可以直接从两张清单读取，减少重复设计和返工。
