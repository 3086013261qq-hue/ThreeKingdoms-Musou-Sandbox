# 资料生产顺序与蓝绿灯设定规范 v1.0

## 一、正式生产顺序

本项目资料施工顺序固定为：

1. 核心设定
2. 人物
3. 时间线
4. 地点
5. 最后再进入 MVU / 完整装配 / 构建

原因：先固定世界底层规则，再据此重塑全员娘化人物；人物定型后再编制《三国演义》主线时间线，最后补齐时间线实际需要的地点，避免先做大量无用地点。

## 二、蓝灯与绿灯

### 蓝灯：总设定
- 全局常驻。
- 只保存少量、任何场景都必须成立的底层世界规则。
- 目标是让模型始终知道“这是什么世界”。
- 不在蓝灯里堆角色百科、具体招式、兵器细则或阵营细节。

### 绿灯：展开设定
- 默认关键词触发。
- 用于解释蓝灯总则下面的具体机制、分类、例外与细节。
- 角色能力、特殊兵器、势力制度、战斗机制等原则上均为绿灯。
- 目标是“需要时才加载”，控制上下文 token。

## 三、项目当前总方向

- 《三国演义》：负责剧情与时间线骨架。
- 《真·三国无双》系列：负责人物视觉、武器气质、英雄化与一骑当千式战斗表现参考。
- 主要三国人物：全员娘化。
- 不因为娘化而抹掉原人物的核心性格、政治立场、人物关系与经典剧情职能。
- 具体魔改规则先在设定阶段确认，再进入人物阶段。

## 四、咩咩全栈边界

蓝灯 / 绿灯只是世界书启用策略，不改变全栈正文模板。
所有正式设定仍使用：

```text
<核心设定:名称>
...
</核心设定:名称>
```

角色正文仍严格采用 `chara-v1`；技能与战斗能力不得擅自塞进角色模板，而应另建同名绿灯能力条目。
