# 全阵营武道等级平衡与无双席位 v0.3

> 状态：DRAFT / 作为 `manifest/character-roster.v0.3.json` 的武道平衡说明。角色正文尚未开始生产。

## 一、调整目的

v0.2 的角色池已经扩展到89名正式候选，但无双武境仍沿用早期5人方案，造成阵营间顶尖个人武力观感失衡：

- 曹魏仅张辽一名无双，深厚将领池缺少足够的顶级武力锚点；
- 蜀汉拥有关羽、张飞、赵云三名无双，顶尖层明显集中；
- 孙吴没有无双，导致小霸王、斗将与锦帆猛将的个人武力被压低；
- 晋与群雄也缺少与自身时代定位相匹配的武力天花板表达。

本轮不改变既有武境体系，不新增第六档，只重新分配89名候选的默认武道等级。

## 二、无双总量

正式人物卡候选：89。

无双总数固定为 **12人**，约占正式候选的13.5%。

无双仍是极少数顶级武境，不按阵营人数机械平均分配。

## 三、最终无双名单

### 曹魏｜3

- 张辽：军团统帅型无双；威震敌阵，兼具个人破阵与统兵能力。
- 典韦：近身护主型无双；极端短距离杀伤与护卫能力达到顶点。
- 许褚：重装力量型无双；以体魄、巨槌与正面压制构成魏军力量天花板。

曹魏的整体结构为“少量无双 + 极厚名将层”，强调人才池、组织能力与多类型将领储备。

### 蜀汉｜4

- 关羽：武圣型无双。
- 张飞：爆发猛将型无双。
- 赵云：全能救阵型无双。
- 马超：西凉骑战型无双。

蜀汉的顶尖个人武力最为集中，但并不意味着阵营整体强度永久高于其他势力；资源、军势、谋略与组织仍受蓝灯规则约束。

黄忠、魏延、姜维、关银屏继续保留名将，避免无双泛滥。

### 孙吴｜3

- 孙策：小霸王 / 高速扩张型无双；以猛烈节奏和近身爆发代表江东开拓期武力天花板。
- 太史慈：刚烈斗将型无双；强调正面对决、硬碰硬与稳定破阵。
- 甘宁：锦帆突袭型无双；强调高速袭击、水陆机动与小部队突穿。

孙吴由此形成三种互不重复的顶级战斗风格，而孙坚、周瑜、吕蒙、黄盖、周泰、凌统等继续构成深厚名将层。

### 晋｜1

- 邓艾：后期奇袭统帅型无双；强调山地、长途奇袭、复杂地形推进与亲自破局。

晋的核心优势仍然是权术、整合、后期组织力与人才配置，不需要大量无双堆叠。

### 群雄｜1

- 吕布：天下第一猛将 / 无双武境最高个人战力标杆。

吕布不另立“无双之上”的第六武境。她代表同一无双层内部的最高个体上限；其他无双可以在不同领域接近、克制或短时抗衡，但不默认拥有与吕布完全相同的纯个人正面战力。

## 四、名将层仍然重要

本轮升入无双的7人：

- 典韦
- 许褚
- 马超
- 孙策
- 太史慈
- 甘宁
- 邓艾

因此武道分布由 v0.2 的：

- 无双5
- 名将31
- 骁将16
- 武人33
- 未入武境4

调整为 v0.3：

- **无双12**
- **名将24**
- **骁将16**
- **武人33**
- **未入武境4**

名将不是“低一档就必败”。按已封版的武境规则，夏侯惇、徐晃、张郃、庞德、王异、黄忠、魏延、姜维、关银屏、孙坚、周瑜、吕蒙、黄盖、周泰、凌统、夏侯霸、华雄、孟获、公孙瓒、吕玲绮、祝融等名将，在武器克制、地形、伤势、疲劳、情报、心理、军阵与多人配合等条件下，仍可对无双形成真正威胁。

## 五、阵营武力气质

- 曹魏：顶尖武力不如蜀集中，但无双类型齐全、名将层最厚，适合组织化战争。
- 蜀汉：无双最集中，个人英雄色彩最强，但资源与组织约束仍然真实存在。
- 孙吴：顶级武力集中于开拓、斗将、突袭三类，水军与都督体系提供额外战争优势。
- 晋：个人无双数量少，但后期统合、军政资源与权术能力强。
- 群雄：整体离散，吕布拥有最夸张的个人战力峰值，但不代表群雄是统一强势阵营。

## 六、生产规则

人物正式生产时：

1. `武道等级` 直接使用 `character-roster.v0.3.json`；
2. 不因后续外貌设计而随意升降武境；
3. 如需改动无双名单，必须先更新 roster、本文与 QA，再生成角色正文；
4. 吕布保持“无双层最高个人标杆”，但不得增加额外武境等级；
5. 无双只定义综合个人武道上限，不替代统率、谋略、政治、阵营资源与剧情级别。
