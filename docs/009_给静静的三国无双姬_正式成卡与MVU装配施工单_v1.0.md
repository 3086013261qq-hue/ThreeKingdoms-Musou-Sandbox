## 4. MVU 正式业务

MVU 只有：
1. 五阵营锁屏画廊；
2. Page 1「阵营亲和」；
3. Page 2「名姬风华录」。

禁止增加剧情页、地点页、角色详情页、背包页、百科页、状态页。

### 4.1 阵营亲和

唯一真值：每轮 assistant 回复末尾唯一完整的：
`<faction_affinity>...</faction_affinity>`

五项固定：曹魏、蜀汉、孙吴、晋、群雄。

规则：
- 初始值全部 0；
- 范围 -100～+100；
- 每轮精确继承上一合法块；
- 先结算本轮真实事件，再输出新的累计值；
- 时间流逝本身不得自动刷分；
- 对单个角色的私人互动默认只影响咩咩原生角色好感，不自动传播为阵营亲和；
- 不建立 `stat_data` 第二份阵营真值。

增减刻度沿用冻结文件：
- 正向：+0 / +1 / +3 / +5；
- 负向：-1 / -5 / -10 / -50。

必须有输出保险，确保正常 assistant 回复末尾始终恰好一个完整合法块；同一已结算事件不得跨楼重复收费。

runtime 必须读取聊天历史里“最新合法完整块”，不能只看固定楼层，也不得把 assistant 判断写死成 `role === 'assistant'`；兼容 SillyTavern / Tavern Helper 常见 `is_user !== true` 且 role 缺失的消息形状。

解析失败：保留上一合法值，禁止清零。

### 4.2 名姬风华录

收藏池固定为 89 名正式人物。

数据源：咩咩原生人物关系 / 好感记录。

禁止为 89 人再建第二套好感变量。

点亮规则：
- 某正式人物第一次进入咩咩原生关系/好感记录，即永久点亮；
- 死亡、退场、关系恶化后仍保持已记录；
- 未邂逅显示 `???`；
- 多娜、咩娘不计入 89。

每张已点亮名片只显示：
- 姓名；
- `♥ 咩咩原生好感度`。

不得显示武器、武道、简介、人物正文，不做点击详情弹窗。

支持轻量筛选：
`全部 | 曹魏 | 蜀汉 | 孙吴 | 晋 | 群雄`

显示：`已录 X / 89`。

- 所有可点击控件使用真实 `<button>`；
- 触控区域至少 44×44px；

- MVU 展开/收起、锁屏进入、左右翻页、页签切换必须可在 Android 触控环境正常使用。
