# 角色池资料来源与筛选说明 v0.1

## 目的

本文件只说明“为什么这些人物进入候选池”，不把资料来源说明写入正式世界书正文。

## 主要来源层

1. 《三国演义》：决定人物是否具有稳定主线职责、关键事件参与度与跨篇章重要性。
2. 《真·三国无双8 / 8 Empires》：提供大规模无双武将候选池、阵营归类、标志武器与英雄化角色识别方向。
3. 《真·三国无双 ORIGINS》：用于复核早期三国英雄轴和当前系列仍重点强调的人物。
4. 《三国志》系列人物页：用于补充未进入无双可玩池但在《三国演义》主线中不可缺少的人物。

## 筛选原则

《真·三国无双8 Empires》拥有 94 名无双武将，但本项目不照单全收。

第一轮正式人物卡只保留：
- 跨篇章核心君主；
- 主要统帅与猛将；
- 关键军师与政治人物；
- 对主要人物关系有稳定长期作用的人物；
- 具有足够鲜明无双化外观、武器或战斗身份的人物。

下列情况优先降为 C 级时间线 NPC：
- 只承担单一事件功能；
- 与其他人物职责高度重复；
- 游戏可玩但《三国演义》主线存在感较弱；
- 当前没有必要承载长期互动。

## 当前规模

- 正式人物卡候选：67
- C级时间线NPC首批：18

该数字为 v0.1 草案，不视为封版；人工复核后允许升降级、增删与调整阵营归类。
