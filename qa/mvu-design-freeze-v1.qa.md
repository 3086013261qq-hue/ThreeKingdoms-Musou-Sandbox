- [x] 所有点击控件要求真实 `<button>`。
- [x] 触控区域最小 44×44px。
- [x] 支持左右 swipe 且不得破坏纵向聊天滚动。
- [x] 只预载锁屏当前页与相邻页。
- [x] 禁止大面积持续滤镜和常驻粒子。
- [x] 媒体加载失败时必须有可操作 fallback。
