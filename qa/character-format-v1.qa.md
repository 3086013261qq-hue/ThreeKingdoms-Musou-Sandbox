# 人物条目格式 v1 QA

## 基线
- 母版：咩咩制卡·全栈 v1.0.0 / `chara-v1`
- 项目扩展规范：`docs/002_人物条目格式与原名保留规范_v1.0.md`

## 检查结果

### 1. 原名保留
PASS。

正式人物姓名保留原版，不进行性转改名。曹操、刘备、孙权、吕布、诸葛亮等继续使用原名；世界底层规则已经负责“人类自出生起皆为女性”。

### 2. 固定新增字段
PASS。

在 `chara-v1` 身份信息区固定新增：
- 阵营
- 角色定位
- 标志性武器
- 武道等级

字段顺序统一为：
`名字 → 性别 → 阵营 → 角色定位 → 标志性武器 → 武道等级 → 印象`。

### 3. 阵营字段边界
PASS。

人物正文只记录当前制卡锚点的正式所属；完整转阵营履历交由时间线与阵营绿灯，不在人物正文堆叠一生履历。

### 4. 标志性武器字段边界
PASS。

只负责人物识别，不展开招式、武器机制或技能树；详细能力继续使用 `<核心设定:角色名·能力>` 绿灯。

### 5. 武道等级与核心设定一致性
PASS。

统一采用：
`未入武境 / 武卒 / 武人 / 骁将 / 名将 / 无双`。

武境不表示绝对胜负，不覆盖谋略、统率、政治、伤势、地形与克制关系。

### 6. 主要/次要角色一致性
PASS。

`worldbook/characters/main/` 与 `worldbook/characters/other/` 使用同一人物正文格式，仅装卡 order 区间不同。

## 结论

人物生产格式已锁定，可进入正式人物批量生产。
