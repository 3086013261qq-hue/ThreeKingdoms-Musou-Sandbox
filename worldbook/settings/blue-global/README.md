# 蓝灯｜全局常驻总设定

这里只放整个《三国无双姬》世界始终成立的少量底层规则。

原则：
- 常驻启用；
- 不依赖关键词；
- 正文只描述世界本身，不写“参考哪个作品”“施工时如何取材”之类的元说明；
- 负责总则，不负责百科式展开；
- 尽量短而高密度，避免常驻 token 膨胀；
- 具体机制、例外、角色能力、兵器与阵营细节全部下沉到 `../green-triggered/`。

1. `001_三国无双姬世界基调.md`
2. `002_女性世界与老年御姐化.md`

4. `004_无双武人与战场法则.md`
5. `005_天下阵营与军势格局.md`
6. `006_无双武姬的战斗方式.md`
7. `007_气与武境.md`
8. `008_文武并立与军师之道.md`

其中：
- 004 只负责“大规模战争为何在高武世界仍然成立”的战争层规则；
- 006 只负责“无双武姬个人如何战斗”的个人层规则；
- 007 负责统一强弱机制；
- 008 负责文武并立，避免军师、谋臣、统帅被单纯武境覆盖。

资料来源优先级、时间线取材边界与人物制作依据属于 `docs/` / `sources/` 的施工规范，不进入蓝灯正文。
