# 核心设定

本项目核心设定沿用《火影姬世界》已经验证过的蓝灯 / 绿灯分层思路，但正文格式仍严格服从咩咩制卡·全栈 v1.0.0。

## 蓝灯：全局常驻总设定
- 目录：`blue-global/`
- 数量必须少，负责定义整个世界始终成立的底层规则。
- 装卡时作为常驻条目，不依赖关键词触发。
- 只写“总则”，不把具体角色、具体武器、具体阵营或具体招式全文塞进蓝灯。

## 绿灯：关键词触发展开设定
- 目录：`green-triggered/`
- 对蓝灯总规则进行具体展开。
- 默认不常驻，命中设定名、角色名、武器名、阵营名等关键词时再启用。
- 角色能力配套 `<核心设定:角色名·能力>` 也属于绿灯层。

## 正文格式
统一使用：

```text
<核心设定:名称>
...
</核心设定:名称>
```

禁止把“蓝灯/绿灯”写成第五种世界书正文格式；它们只是世界书的启用/触发层级。
