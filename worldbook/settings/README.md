# 核心设定

本项目核心设定采用已经验证过的蓝灯 / 绿灯分层思路，但正文格式仍严格服从咩咩制卡·全栈 v1.0.0。

## 当前封版状态
- 蓝灯：8 条，常驻，order `398～391`。
- 绿灯：50 条，关键词触发，order `380～331`。
- 蓝灯 manifest：`manifest/blue-global-settings.v1.json` v1.4。
- 绿灯 manifest：`manifest/green-triggered-settings.v1.json` v1.8。
- 八条蓝灯均已完成第一轮绿灯展开。
- 核心设定阶段完成后，下一正式生产阶段为人物；不得在人物生产中另造第二套世界底层规则。

## 蓝灯：全局常驻总设定
- 目录：`blue-global/`
- 数量必须少，负责定义整个世界始终成立的底层规则。
- 装卡时作为常驻条目，不依赖关键词触发。
- 只写“总则”，不把具体角色、具体武器、具体阵营或具体招式全文塞进蓝灯。

## 绿灯：关键词触发展开设定
- 目录：`green-triggered/`
- 对蓝灯总规则进行具体展开。
- 默认不常驻，命中设定名、角色名、武器名、阵营名等关键词时再启用。
- 角色能力配套 `<核心设定:角色名·能力>` 也属于绿灯层。
- 绿灯触发词优先使用具体短语，避免无意义的高频词造成变相常驻。
- 只有确有双层语义时才允许同一关键词触发多条绿灯；当前明确保留的例子是“政治联姻”，同时触发阵营外交层与家庭婚姻层。

## 正文格式
统一使用：

```text
<核心设定:名称>
...
</核心设定:名称>
```

禁止把“蓝灯/绿灯”写成第五种世界书正文格式；它们只是世界书的启用/触发层级。
