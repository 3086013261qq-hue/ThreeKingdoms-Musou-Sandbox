# 绿灯｜关键词触发展开设定

这里保存蓝灯总规则的具体展开，以及角色能力、特殊兵器、阵营体系、战斗机制等按需资料。

原则：
- 默认关键词触发；
- 一条只负责一个独立概念；
- 关键词必须覆盖正式名与常用别称；
- 触发词优先使用具体短语，避免把“无双”“气”“名将”“军师”“谋略”这类高频单字直接设为关键词，防止绿灯变相常驻；
- 角色能力使用 `<核心设定:角色名·能力>`；
- 不把所有展开条目一起常驻；
- 若某条后来被证明是全世界任何场景都必须知道的底层规则，再单独评估是否提升为蓝灯，禁止随意升级。
