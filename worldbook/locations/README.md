# 地点

使用全栈原生 `<地点:名称>介绍:...</地点:名称>`，只写客观空间资料。

## 施工规则
- 地点卡只描述空间事实：地理位置、地形水系、道路与关隘、城防、城区结构、资源与通行特征。
- 不写人物心理、阵营立场、战役结果、某年某人占领或死亡等动态剧情；这些统一由时间线负责。
- 同一地点可保留稳定别称或古称，但避免把时代变化写成第二套剧情。
- 宏观区域与具体城池只有在空间功能明显不同、且会被独立触发时才拆分。
- 对现代定位存在争议的古战场，只保留稳定地貌与交通功能，不宣称唯一考古坐标。
- 正式文件使用 `NNN_地点名.md`。

装卡 order 目标段：100~1。
